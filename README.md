# 🍴 Foodies Heaven - Modern Restaurant Menu

### 🌐 Live Demo
You can view the live project here:  
 https://aina145.github.io/Hotel-menue-page/

This is a premium, high-end digital restaurant menu experience built with modern web technologies. 🚀

### 📖 Description
This was a **practice project** where I explored modern CSS techniques, glassmorphism, and AI-generated imagery. It features a fully responsive design, interactive theme toggling, and smooth scroll animations. "Bas practice tha blaa bla hahaha" - but it turned out pretty cool!

### ✨ Features
- **Modern UI**: Clean, card-based layout with premium typography.
- **AI-Generated Assets**: High-resolution food photography for every item.
- **Glassmorphism**: Subtle translucent effects for a professional feel.
- **Interactive**: Theme toggle (Dark/Light) with persistence.
- **Responsive**: Works perfectly on mobile, tablet, and desktop.


---

### 🛠️ Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom animations, Grid, and Flexbox.
- **JavaScript**: Theme persistence and scroll detection.
- **AOS/Animate.css**: For those smooth entry effects.
